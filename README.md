# Cheetah - RC Car
This project is a remotely-controlled car. Currently it consists of 3 subprojects: Pilot, Antenna and Rebel.
Pilot is a smart phone app which let's the user control the car. Rebel is the car itself.
Antenna is an intermediate device between Pilot on smart phone and Rebel to fill the missing unprivileged device on smart phone for long-range wireless communications.
